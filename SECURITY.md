# Security policy

SealedCash is privacy-sensitive software. Please do not disclose vulnerabilities in a public issue.

Email [support@sealedcash.com](mailto:support@sealedcash.com) with a clear description, affected version or commit, reproduction steps, and the security impact. Do not include private keys, wallet seed phrases, access tokens, or other credentials in a report.

We will acknowledge a report as soon as practical and coordinate a fix or mitigation before public disclosure. Supported versions are the latest published release and the default branch.
