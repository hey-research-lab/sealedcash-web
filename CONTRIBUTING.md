# Contributing

Contributions to SealedCash are welcome. Please open an issue before substantial changes so the scope and privacy implications can be reviewed.

## Development expectations

- Keep claims in the interface aligned with verified capabilities.
- Never add private keys, production RPC URLs, deployed addresses, or credentials.
- Keep browser-only code free of server secrets.
- Run `npm run typecheck`, `npm run test`, and `npm run build` before opening a pull request.
- Include a focused explanation of changes and any security or privacy trade-offs.

By contributing, you agree that your work is provided under the repository's MIT license.
